# 推箱子游戏 🎮

一个经典的推箱子（Sokoban）游戏，使用纯HTML/CSS/JavaScript开发。

## 🎯 游戏说明

将所有箱子推到目标点上即可过关！

### 操作方式
- ⬆️⬇️⬅️➡️ 方向键：移动玩家
- R 键：重置当前关卡
- 按钮：切换关卡

### 游戏元素
- 🧑 蓝色小人：玩家
- 📦 棕色方块：箱子
- 🎯 绿色圆圈：目标点
- 💛 金色方块：箱子已到位
- ⬛ 黑色砖块：墙壁

## 🚀 在线游玩

访问：[https://xxm177.github.io/sokoban-game](https://xxm177.github.io/sokoban-game)

## 📦 本地运行

直接用浏览器打开 `index.html` 文件即可！

## 🎮 关卡

游戏包含4个精心设计的关卡，难度逐渐递增。

## 💡 提示

- 箱子只能推，不能拉
- 小心不要把箱子推到角落，否则可能无法完成关卡
- 尽量减少移动步数，挑战自己的最佳记录！

## 🛠️ 技术栈

- HTML5 Canvas
- CSS3
- 原生 JavaScript
